# WiFoot Manager — técnico de futebol estilo Brasfoot

Repositório: github.com/Junin12/WiFoot-Manager. Leia o README.md antes de começar.

HTML/CSS/JS puro, sem build. Abra `index.html`; progresso salvo no IndexedDB. Modos Treinador (com opção SAF) e Carreira. Dados em `data.js` e `db/`; tem `appsscript/`, `loja/` e `tools/`.

## Regras
- Textos do jogo em português do Brasil.
- Mantenha a stack atual; não adicione frameworks ou build sem o usuário pedir.
- Rode os testes existentes (se houver) depois de cada mudança.
- Faça commit das mudanças; não faça push sem o usuário pedir.
